Original physical formula and operation order

For ir=1..nreg, ifis=1..32, h=1..370:
 product64=real(NUSIGF(im,ifis,h),real64)*phi64(KEYFLX(ir),h)
 fis64=fis64+product64
For g=1..370, inside the same region/fission-slot nest:
 contribution64=real(CHI(im,ifis,g),real64)*fis64
 contribution64=contribution64*rho64
 q64(KEYFLX(ir),g)=q64(KEYFLX(ir),g)+contribution64
Every remaining native unknown starts and stays positive numerical zero.
The complete original source loop nest is byte-identical to B2N. Multiplication
and addition stay separate; there is no FMA assumption, reassociation, clipping,
additional normalization, reduction intrinsic, or new physical model.
The original volume integral retains g->ir order; volume64 has already been
bit-checked equal to the original real(volume32,real64) operand. The original
positive-first-integral, finite/nonnegative, range and demote checks remain.
MACRO0 is LCMEQU of the entire selected MACROLIB, with only every NUSIGF array
set to +0.0_real32. Original SPOT-FROZEN/SPOT-KEFF metadata is added. CHI, all
scattering groups, nested isotope/material physics, and every other physical
record retain the original tree. The full parent MICROLIB2 remains in GLOBAL64
and PROJECTED archive. Full-tree READ recomputation detects other record edits.

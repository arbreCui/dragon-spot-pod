# Phase A9b / B2x same-call returned-close validation

B2x freezes the deployment-default-OFF host route from one immutable
`RETURNED/1` archive to one `CLOSED/1` axial/archive pair. The production
CLE procedure owns a private feedback copy, admits its lagged returned
generation, and then owns every mutable intermediate through the exact order

```text
RETURNED -> private FEEDBACK -> SPOR64V admission
         -> ASM SPOD 1 FIXB -> FLU TYPE K
         -> SPOSTATE -> SPOLEAK -> SPOR64X -> B2w
```

No shipped calculation selects `SpotCloseR64`. Its rank and already-frozen
inner-solver controls are source constants, not caller inputs, and the route
contains no relaxation, damping, clipping, fitting, retry, or outer
acceptance scalar.

## Seconds-scale evidence

The gate deliberately separates structural custody from numerical execution.

- The real CLEPIL/OBJPIL compiler compiles the production procedure and
  validation OFF/ON selection shapes. A directed static mutation suite locks
  the private-copy/admission/order/identity contract, both exact adapter
  ABIs, their dispatcher branches, and the `FLU2DR` strict terminal predicate
  and cap failure before label 410.
- A small executable invokes the production `SPOR64V` and `SPOR64X`
  adapters through ABI, parser, downstream-failure, pointer-order, and
  success cases. Its B2w is a capture stub, so this is adapter evidence only.
- A second synthetic executable reuses the frozen B2w fixture, calls the real
  `SPOLEAK`, the real `SPOR64X`, and the real B2w gate. It includes one
  content rejection with two fresh zero-write targets and one successful
  close. The real returned-admission adapter is also exercised against a
  valid lagged generation and a child/system `L0` mismatch.
- The production ASM, FLU, SPOSTATE, FLU2DR, dispatcher, and adapter sources
  are strictly compiled. No ASM, FLU, or SPOSTATE symbol is linked into a
  runtime witness; the production host order is structural evidence only.
- The unchanged B2w GANLIB-only posterior reads four XSM evidence objects
  twice, checks the complete detached-content close contract, and must produce
  identical reports without changing any evidence hash.

This is not a numerical solve. Passing proves a statically frozen same-CLE-
call custody route plus the real terminal admission/leakage/close semantics
on synthetic objects. It does not prove that production ASM or FLU executed,
that a real axial field was solved, that the full real online map closed, or
that any radial/axial equation converged accurately.

It also makes no Picard convergence, SPOD truncation accuracy, eigenvalue,
power, benchmark, full-core, or cross-platform reproducibility claim.
Temporary objects and XSM files are removed on every runner exit. Before
receipt freeze, the complete gate reports `PENDING-MAIN-AUDIT`; the frozen
gate must instead verify every pinned input and report `FROZEN`.

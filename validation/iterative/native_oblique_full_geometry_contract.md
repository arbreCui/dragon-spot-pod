# Complete native geometry: cost preflight and zero-gradient recovery

This stage follows the [selected native-path pilot](native_oblique_track_pilot_result.md).
Its purpose is to replace selected-path evidence with an accountable sum over
every original native track. Qualification remains restricted to geometric
assembly and the manufactured zero-axial-gradient subspace; finite-axial
vacuum transport is a later experiment.

## Complete-track inventory and execution admission

Use real copies of the sealed original track fixture and exact full-flight
reference. Retain all 11,364 planar paths, all four original polar nodes,
both planar orientations and both independent axial signs. Physical-reflection
layouts used only as pilot controls must not be counted twice as native rays.
Every original record must have an explicit multiplicity and output receipt.

Preflight the full set, including groups 51/61/98, heights 1/20 cm, axial
grids 1/2/4, and fixed offset orders 8/16. Count topology intervals, chords,
primitive pieces, the declared input columns, accumulated outputs and replay
storage before any responses are solved. Freeze process batches from these
counts; batching may change storage/work scheduling but not the case matrix.

Use the pilot's actual resource observations when estimating memory. Its
largest numerical RSS exceeded its initial estimate while remaining below
the 512-MiB cap; account for temporary arrays, packing copies and allocator
retention instead of assuming nominal array size is the whole process.
Keep one numerical thread and the 512-MiB/600-second per-process limits.
Record an elapsed-time estimate for the complete primary plus replay work,
not only for the smallest process.

Prefer streamed aggregate response fields and per-batch audit records over
duplicating every chord/source trace. Preserve complete source coordinates,
raw sums and worst primitive witnesses, with recipes sufficient to regenerate
any full trace. A fresh replay may dispose only byte-verified duplicate
temporary files after recording hashes and sizes. Freeze output bounds and
a disk reserve of at least 1 GiB. If the complete matrix cannot fit, preserve
the cost failure and design a separate bounded implementation; do not turn a
new path subset into a whole-geometry qualification.

## Full zero-gradient action and native measures

For each angular state retain all eight original regional volume-source
coordinates and all six incoming radial-surface coordinates. The source is
constant in z only for this manufactured subspace. The independent exact
one-dimensional angular flight supplies top/bottom inflow at its actual
entry position, so the oblique solution should recover the already qualified
exact radial companion. These angular inflows are manufactured fields, not
physical vacuum conditions or piecewise-constant axial boundary data.

Map every repeated segment visit to the original region without combining
distinct source coordinates. Retain physical lengths `h2*ZMU`, original
total-cross-section precision, angular factors and `wei*wzmu/2` half weights.
Construct geometric volume/current measures directly from offset integration.
Accumulate unnormalized contributions first, retaining separate ledgers for
native stored volume/surface normalizers. A measured normalizer difference
must not be absorbed by a fitted correction. Do not insert native PJJ
completion into the exact companion.

Recover full directional regional integrals and radial outgoing currents,
then reconstruct scalar flux and Jx/Jz with the original native moment
conventions. Compare with the frozen complete exact operator and its saved
input cases, not with the distinct tabulated native kernel. Use the previously
declared noncancelling induced-current scales where angular cancellation
makes a net-current relative error unavailable.

Only after complete-track recovery passes, rebuild the six-surface common
white response from this recovered zero-gradient action and compare its
reclosed fields with the frozen exact common-white companion. The same
return must mix every retained polar node and both axial signs. This is
zero-gradient manufactured white recovery; it does not qualify common-white
closure coupled to physical axial escape.

coverage and comparison baselines. Geometry, source assembly, pointwise
recovery, whole-operator recovery and white algebra use 5e-12. Raw primitive,
cell and global balance use 1e-10, and physical unit responses must remain
nonnegative without clipping. Gate quadrature-dependent assembled recovery
at order 16; retain order-8 errors and every failed check. Compare each
axial grid with the same zero-gradient exact reference, rather than treating
adjacent-grid agreement as evidence of general axial convergence.

Verify every original path contribution is present exactly once per declared
orientation/sign/polar state. Audit geometric and stored-normalizer ledgers,
complete-track sum order, and common-white normalization separately. Re-run
the full declared matrix from fresh copied inputs and archived source.

Passing admits full native geometric assembly only in the manufactured
zero-gradient subspace. A subsequent physical-boundary experiment must
still retain all regional/axial source coordinates, set actual top/bottom
conditions, solve radial common white return with axial escape, and establish
an independent accuracy/convergence basis. Native table partition equality
remains failed. Multigroup/fission eigenproblems, POD training, production
sources, shared builds and live D4 runs remain outside this stage.

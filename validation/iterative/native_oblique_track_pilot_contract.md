# Native oblique-track pilot: preserve real geometry before full aggregation

The [manufactured oblique-strip experiment](oblique_strip_geometry_result.md)
qualifies actual axial crossings, positive offset quadrature, shared-face
continuity and independent analytic controls. Its low-order current errors
also show why small balance defects cannot replace an accuracy test.
The next experiment transfers this construction to original native ray paths.

## Read-only inventory and cost preflight

Use real copies of the sealed directional fixture and the qualified
[exact full-flight companion](exact_native_flight_result.md) inputs. Do not
extract a new native library, change the running decks or invoke a shared
build. Record the source manifests before selecting any ray.

First enumerate all original planar paths, their ordered material-region
sequences, physical lengths for each original polar factor, surface entry
and exit identities, multiplicities and weights. For groups 51/61/98, also
record total optical lengths and individual-segment optical extrema. Keep
this inventory read-only; it is not a new angular quadrature or source basis.

Choose a deterministic small path sample before solving any responses:
the shortest and longest physical paths, the fewest/most interior segments,
and the smallest/largest group optical lengths, deduplicated by original
path identity with lowest-index ties. Include a central-ranked path under
each same ordering. Publish selected identities and their coverage; add no
paths in response to favorable or unfavorable numerical results.

Retain all original polar nodes and both axial signs for each selected path.
Before running, enumerate topology intervals, quadrature nodes, pieces,
source columns, output bytes and expected work for each candidate process.
Freeze the finite matrix and batching only after this count fits the
512-MiB/600-second per-process budget. If it cannot fit, preserve the preflight
as blocked by cost and design a separate bounded contract; do not silently
drop polar nodes, source columns or failed configurations.

## Exact native path bridge

Use every original interior segment of each selected path, including
repeated visits to a material region. Physical path coordinate increments
are the original planar segment length times ZMU. The axial component is
`+/-sqrt(1-1/ZMU^2)` and is independent of planar travel orientation.
Reversing planar travel reverses segment and surface order only.

Native material-region inputs map explicitly to each visited segment. Keep
segment/axial-cell source coordinates in the geometric sweep, then document
their exact assembly back to the eight original regional source coordinates.
This assembly must not average distinct axial cells or replace the flight
with a scalar regional inverse. Primitive coefficients use the separately
qualified exact exponential companion, without the native PJJ completion.

The preflight should consider heights 1/20 cm, axial grids 1/2/4/8 cells,
and positive offset orders 8/16. Preserve all original radial ray weights
and half weights for independent axial signs. Selected-track ledgers are
partial contributions only: never rescale them to the full native volume or
surface measure, and never infer a whole-geometry scalar error from them.

## Frozen controls and admissibility

Before execution, enumerate every input, scale and zero-output convention.
At minimum retain constant-solution controls, independent cell and incoming
face units, a nonuniform axial source, and matched axial inflow from the
original-path exact one-dimensional flight. The matched control must recover
the exact full-flight companion's source/inflow action on each selected path,
not the distinct native table kernel. Recover directional integrals and
outgoing amplitudes before aggregating scalar or current moments.

Check exact geometric measures, positive responses, primitive/cell/global
balances, shared-face currents and both directional reflections. The
pointwise, geometry and shared-face target remains 5e-12; raw balance remains
1e-10; physical responses must remain nonnegative without clipping. Specify
the quadrature-dependent matched recovery target before solving, and retain
all order-8 and order-16 errors even when a target fails. The 8-to-16 change
is not a true-error bound for the nonuniform heterogeneous source.

Use original-source coordinates and independent 1D calculations to check
assembly. Keep geometric and stored-native normalizer ledgers separate.
Batch nodes/source columns as needed without truncating the declared basis.
Archive the finite plan, original-to-pilot mapping, raw fields, failed
controls, source snapshots and resources, then replay from a fresh directory.

## Qualification boundary

Passing qualifies only the selected native paths and their explicit source
mapping. The next full-geometry experiment must still account for every
native track, establish quadrature accuracy under its resource budget,
recover the complete exact radial companion, and solve one common radial
white return across all retained polar states and axial signs.

Native finite-axial-mesh convergence, multigroup/fission eigenproblems and
POD training remain unqualified. Production sources, shared binaries and
live D4 work remain outside this pilot. This contract has not been executed
as part of the manufactured-strip artifact.
